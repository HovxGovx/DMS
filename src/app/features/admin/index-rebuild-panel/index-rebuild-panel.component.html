Index de recherche

La recherche s'appuie sur un index des documents publiés. Le reconstruire remet l'index en accord avec la base, sans redémarrer le serveur.

Quand reconstruire ?
  • un document publié n'apparaît pas dans la recherche, ou un document retiré y apparaît encore ;
  • après une évolution des champs indexés (nouvelle version de l'application) ;
  • après une restauration de la base de données.

L'index est vidé puis rempli à nouveau en une seule fois : pendant l'opération, la recherche continue d'utiliser l'ancien index.
